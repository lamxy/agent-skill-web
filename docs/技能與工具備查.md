# 技能與工具備查

本文件是專案的技能供應鏈台帳。新增、升級、停用或移除技能時，必須同步更新本文件與 `skills-lock.json`。除程式碼識別字、命令與官方名稱外，備查內容一律使用中文。

## 安裝原則

1. 優先安裝到目前專案 `.agents/skills/`，避免污染其他專案；不得使用全域 `-g`。
2. 優先官方或高可信來源，核對安裝量、倉庫聲譽、授權與技能內容。
3. 使用 `--copy` 保存專案內副本，使用 `skills-lock.json` 保存來源與內容雜湊。
4. 安裝命令關閉匿名遙測；技能本身不得攜帶未審核的可執行腳本、高權限網路操作或破壞性命令。
5. 不因「已安裝」自動信任；每次使用前仍按 `SKILL.md` 的路由只讀取必要參考。
6. `find-skills`、官方插件與其他可信渠道沒有合適候選時，才檢查 `msitarzewski/agency-agents`；它是備援 Agent 角色來源，不是可直接整庫安裝的 Skill registry。
7. 每個任務自主搜尋 1 或 2 輪，最多不超過 2 次；沒有合格候選時立即採用官方、大廠及成熟社區通用模式，不讓技能搜尋阻塞第一期交付。

Agent 技能標準安裝命令：

```bash
DISABLE_TELEMETRY=1 npx -y skills add <owner/repo> --skill <name> -a codex -y --copy
```

此命令只適用 Agent 技能專案級安裝；平台產生給終端使用者的三段式 install／uninstall 腳本另依架構契約處理，不得混為同一政策。

## 工具

### Agency Agents 備援目錄

- 來源：`https://github.com/msitarzewski/agency-agents`，MIT 授權的社區 Agent 角色庫。
- 使用時機：`find-skills`、官方插件、現有專案技能與其他可信渠道都沒有適配候選時，按任務檢查單一相關角色，例如 Backend Architect、Database Optimizer、Identity & Access Engineer、Frontend Developer 或 Code Reviewer。
- 安全邊界：倉庫包含桌面應用、`scripts/install.sh` 與 `scripts/convert.sh`；本專案禁止自動執行這些內容，也禁止整庫安裝。只讀審查單一 Markdown 後，才能專案級複製或改編。
- 記錄要求：採用時保存原始檔案 URL、commit SHA、內容雜湊、採用原因、修改範圍與使用說明；拒絕時記錄不適配或安全原因。
- 當前狀態：僅登記為備援搜尋渠道，尚未從該倉庫安裝或複製任何 Agent。

### Task Master CLI

- 命令：本機實際入口為 `task-master`；需求中提到的 `taskmaster` 是概念名稱，不是 PATH 內的可執行檔。
- 用途：以 `list`、`next`、`show`、`set-status`、`update-task` 管理可執行任務、依賴與狀態。
- 執行邊界：試跑與學習完成後，所有 `list`、`next`、`show`、`set-status` 與內容更新命令都在目前專案根目錄執行；不得再使用 `/tmp` 的 `.taskmaster` 連結。
- 失敗處理：`update-task` 必須讀取專案 `.taskmaster/config.json`；只有指定 tasks 檔而沒有專案 config 時會錯誤回退到缺少 API key 的 provider，該次失敗不得視為已保存。

### Vercel Labs Skills CLI

- 命令：`npx skills`。
- 用途：搜尋、安裝、列出與鎖定 Agent Skills。
- 安裝範圍：本專案使用 project scope、Codex agent、copy 模式；`skills-lock.json` 是機器可讀備查。
- 隱私：安裝與搜尋時設定 `DISABLE_TELEMETRY=1`。

### RTK

- 命令：所有 shell 命令以 `rtk` 開頭；需要原始輸出時使用 `rtk proxy`。
- 用途：壓縮冗長終端輸出，降低無關日誌；長命令必須保留 session id 並等待真實退出碼。

# 使用者指南

## 安裝與解除安裝

從已發布版本頁選擇 OS、Client 與動作，檢查預覽中的命令、殘留說明與 SHA-256 digest，再執行平台產生的 Bash 或 PowerShell 腳本。只從可信平台取得腳本，不執行聊天訊息或第三方貼文中的改寫版本。

腳本安裝失敗時保留原始非零退出碼。安裝成功但遙測暫時失敗時，終端會顯示「安裝成功，資料同步中」；這代表功能已完成，事件會在下次執行平台腳本時依 FIFO 補交。

## 本機資料

- Linux／WSL：`~/.agent-platform/uuid`、`pending_reports.jsonl`、`dead_letter_reports.jsonl`。
- Windows：`%APPDATA%\agent-platform\uuid`、`pending_reports.jsonl`、`dead_letter_reports.jsonl`。
- WSL 與 Windows 使用不同使用者資料目錄，因此 UUID 彼此獨立。

匿名 UUID 依作業系統使用者隔離並持久化。刪除 `uuid` 後，下次執行會生成新 UUID，平台會把它視為新使用者，歷史採用資料不會自動合併。已登入使用者使用 UID，不依賴此檔案。

## 回報問題

提供 package ID、version、OS、Client、動作、退出碼、發生時間與畫面上的結構化錯誤碼。不要提供 queue 全文、環境變數、Cookie、Token、命令輸出中的秘密或個人資料。

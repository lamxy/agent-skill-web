# Task 13 上架 Matrix 實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 依已審核上架頁線框，建立可重載的「系統 × Client」腳本 Matrix，每個 target 獲得獨立命令、版本歷程、複製來源、軟刪除、選項與使用說明，並串接生成器、治理、遙測與隱私契約。

**Architecture:** `package_version_script_targets` 保存每個 target 的目前指標與軟刪除狀態，`script_target_revisions` 以 append-only 快照保存命令、options、usage、殘留與 copy provenance。新寫入以 target/revision 為唯一真實來源；舊 `package_versions` 單命令欄位保留一個相容週期，但生成、送審與驗證均禁止再使用 Cartesian product 推測 target。

**Tech Stack:** TypeScript 7、Fastify 5、Drizzle ORM 0.45、PostgreSQL 17、React 19、Vite 7、Vitest 4。

**Spec:** `design/wireframes/技能池與上架線框.html`、`docs/前端實作指導.md` 「上架頁：Matrix」、`docs/全局開發記憶.md` Task 13、`docs/待決策與延後事項.md` D-3。

## Global Constraints

- 資料庫不建立外鍵、cascade 或 Drizzle `.references()`；只使用邏輯 ID 與普通／唯一／複合索引。
- `ScriptTargetOs` 固定為 `'linux/macos' | 'windows' | 'wsl'`；`ClientRuntime` 固定為 `'claude-code' | 'codex'`。
- 每個 target 首次完整儲存為 `v1`，每次儲存、複製、刪除後重建的內容 revision 單調遞增；revision 永不刪除。
- options、usage instructions、殘留說明、安裝／解除安裝命令都屬於 target revision；release notes 屬於 package version。
- 複製後的目的 target 是獨立快照；後續任何手動 PUT 清除 `copiedFrom`。
- 送審前必須有至少一個 active target，且每個 active target 都有 current revision、兩種命令、usage，不可是 legacy imported revision。
- 線框是 UI 結構契約；第一期以 1024px 以上 PC 為驗收，不擴大手機版範圍。
- `script_version` 與 `options` 在新腳本必傳、遙測 ingress 為相容舊腳本允許缺省；隱私頁必須與白名單同步。

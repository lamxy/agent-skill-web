# 第一期分析頁實作計畫

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可供分析頁直接消費的作者採用分析與員工「我的安裝」API。

**Architecture:** `AnalyticsRepository` 一次取得遙測與版本快照，`AnalyticsService` 以純函式完成聚合、狀態折疊及授權，Fastify plugin 只處理身份與 HTTP。Memory 與 PostgreSQL adapter 共用契約，資料庫保持反範式與零外鍵。

**Tech Stack:** TypeScript 7、Fastify 5、Drizzle ORM、PostgreSQL 17、Vitest 4。

**Spec:** `docs/superpowers/specs/2026-08-25-第一期分析頁設計.md`

## Global Constraints

- 專案文件、測試名稱與使用者訊息使用中文。
- 不建立外鍵、`.references()`、cascade 或跨聚合資料庫約束。
- `uid` 與 `uuid` 分層，不返回合併成功率；待升級清單只含 UID。
- 所有作者分析回應固定包含 `telemetryAssurance: 'best-effort'`、`數據僅供參考` 與可觀測資料缺口。
- 每個生產行為先寫測試、確認預期失敗，再寫最小實作。

- [ ] **Step 3: 實作最小統計與狀態折疊**

```ts
export function wilsonScoreInterval(successes: number, total: number) {
  if (total === 0) return null;
  const z = 1.959963984540054;
  const p = successes / total;
  const denominator = 1 + (z * z) / total;
  const center = (p + (z * z) / (2 * total)) / denominator;
  const margin = z * Math.sqrt((p * (1 - p) + (z * z) / (4 * total)) / total) / denominator;
  return { lower: center - margin, upper: center + margin };
}
```

同檔完成分層成功率、nearest-rank、失敗 cells、當前安裝折疊與語意版本比較；Memory repository 只讀 `MemoryPlatformStore.telemetryRecords` 與版本快照。

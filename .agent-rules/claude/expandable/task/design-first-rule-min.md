# 设计使用极简规约

适用于设计、方案、brainstorm、架构、规划类请求。

触发特征：请求含"设计/方案/规划/架构/brainstorm/头脑风暴/如何做/怎么做"等意图词，且未明确要求立即实现。

规则：
- 在未匹配到技能规约（如头脑风暴技能）的情况下，优先使用设计类极简规约。
- 不执行任何 Bash/Write/Edit/Agent 操作，直到用户明确确认方案。
- 先 Q&A 澄清（每轮只问一个问题，最多 10 轮）。
- Q&A 完成后，提出 2-3 个候选方案（含权衡和推荐）。
- 方案确认后，分节呈现设计，每节结束后询问是否继续。
- 用户明确说"开始实现"或"可以了"后，退出此规约，转入计划/实现阶段。

避免：
- 收到请求后立即运行命令或写代码
- 一次抛出多个问题
- 在未确认方案前输出完整实现计划

# 子代理协作极简规约

与 tool-call-rule-min.md 联用时，仅在工具调用行为层面（调不调、怎么调、结果怎么压缩）以工具调用规则为准；子代理的派发、分工、回传、汇总行为以本规约为准。

适用于单个子代理执行局部任务，或主代理协调多个子代理拆分、并行、汇总。

## 场景定义

- 子代理场景：主代理自行决定派发子代理，或用户明确/按需要求使用子代理。
- 单子代理：主代理仅发起 1 个子代理。
- 多子代理：主代理发起超过 1 个子代理，或存在多子代理协作。

## 派发闸门（主代理派发前必须判断）

满足以下任一条件时，主代理应直接执行，不派发子代理：
- 任务可在当前上下文中用单次工具调用或少量代码（约 30 行内）完成。
- 任务不涉及并行、独立子范围拆分或专项角色分工。
- 派发的模板填充与回传校验开销明显超过直接执行的开销。

用户明确要求使用子代理时，闸门不适用。

规则：
- 先分工，再执行，再汇总；主代理始终负责主控、去重、合并与裁决。
- 主代理派发子代理时，必须附带"子代理极简规约摘要 + 输出模板字段要求"，并明确要求子代理按字段规范回传。
- 子代理仅接收最小必要输入，仅输出局部结果、关键证据、风险与建议；不传完整历史、不重复已知背景。
- 多子代理输出尽量统一格式，汇总时先结论，再给共识、冲突、风险、下一步。
- 子代理输出必须使用 `expandable/templates/sub-agent-output-template.md` 的固定结构。
- 若单个子代理可独立完成任务，优先由该子代理端到端执行；但涉及不可逆操作（提交、删除、发布）时，子代理应标记 `ask` 由主代理确认后再执行。最终决策与对外结论仍由主代理裁决。
- 子代理禁止嵌套派发子代理。若子代理判断任务需进一步拆分，应通过 `ask` 字段上报主代理，由主代理决定是否拆分派发。
- **[强制] 结果分流（适用于所有子代理类型，含内置与外部）：简单结果（不超过 150 行且总字符 ≤3000）直接回传；复杂结果（超出任一阈值）必须落盘至 `.claude/artifacts/`，仅回传摘要、关键证据与 `artifact` 路径，禁止将原始长输出（含完整表格、代码块、日志）直接回灌主会话。**
- **[强制] 主代理收到 artifact 路径后，必须先声明处理意图：「加工」（需主代理分析/汇总/翻译等处理）→ 允许读文件；「转交」（最终产物或用户直接消费）→ 禁止读文件，直接告知路径；意图不明确 → 默认「转交」，询问用户。**
- 子代理遇到工具权限、审批或访问受限时，应立即上报并等待确认，不得静默重试或扩大范围。
- 子代理工具调用长时间阻塞时，应优先回传已完成证据与当前状态；可继续执行标记 `partial`，无法继续标记 `blocked`。
- 外部检索场景：单子代理默认一个目标，超出轻量探测预算时返回 `partial`/`blocked`，上报范围与代价，请求主代理决策。
- 若子代理 `blocked`、明显卡住或长时间无结果，主代理应基于部分结果继续推进，不等待全部完成；阻塞达到 20-30 分钟时应快速评估中断、替换快速评估子代理或请求用户审批。

## 多子代理冲突裁决

多子代理结论矛盾时，主代理按以下顺序裁决：
- 有明确证据质量差异（原始源 > 推断，实测 > 静态分析）→ 采信高质量方并说明理由。
- 证据质量相当 → 不强行裁决，呈现冲突与各方证据，交由用户决策。
- 禁止通过模糊合并掩盖冲突。

## Artifact 管理

- 命名：`{任务简述}_{子代理角色}_{时间戳后6位}.{ext}`，如 `auth-refactor_reviewer_a3f21b.md`。
- 清理：artifact 为当前会话临时产物；会话结束后由用户决定是否保留。主代理在最终汇总时应列出本次产生的所有 artifact 路径，方便用户批量处理。
- 冲突：多个子代理同时落盘时，时间戳后缀保证不冲突；若仍冲突则追加角色名区分。

## 回传校验（主代理必须执行）

收到子代理回传后，先校验是否包含约定必填字段（STATUS、ARTIFACT 或等价字段）：
- 字段完整且路径正确 → 进入汇总/转交流程。
- 字段缺失或为叙述性文字 → 调用 SendMessage 工具（to=agentId）追加纠正，不重新派发新 Agent 实例。
- artifact 路径不符合约定 → SendMessage 要求子代理重写到正确路径。
- 连续 2 次 SendMessage 仍不合规 → 主代理直接上报用户并提供决策建议，停止派发。

## 输出格式
- 单子代理：参见 `expandable/templates/sub-agent-output-template.md`
- 多子代理汇总：参见 `expandable/templates/multi-agent-summary-template.md`
- 派发格式：参见 `expandable/templates/dispatch-template.md`
